# REQ-003：技能系统（SKILL.md 发现 · skill 工具 · 设置分区）

- 状态：已验证（TEST-003 全部通过；活体 UI 对照为追加项，见 TEST-003 §3）
- 关联：DESIGN-003 · TEST-003 · FEATURE-MATRIX 行 `工具/dsh-skill`、`插件体系/client-ui-skill`
- 日期：2026-10-30

## 1. 背景与证据

DSH 把「技能（skills）」作为插件家族的一等公民：技能是文件系统上的指令包（SKILL.md），
模型可发现并按需加载其指令来获得某类任务的专业打法。mygo 完全没有技能概念
（README「已知差距」第 2 条）。

> 证据：
> - `.dsh-ref/dsh-package.json`：`dsh-skill`、`dsh-skill-filesystem`（文件系统技能）、
>   `dsh-skill-badge` + `experimental-badge-skill-bundle`（技能徽标）、`dsh-tool-skill`
>   （模型侧技能工具）、`client-ui-skill`（技能 UI）。
> - `.dsh-ref/gui-index.js`：`SkillOutlineRegular/Medium` 图标（技能有独立界面入口）。
> - 本仓库 README「与初代的已知差距」第 2 条："技能（skills）、工作流编排、终端面板未包含"。
> - 格式假设（§6 声明）：SKILL.md = YAML frontmatter（`name`、`description`）+ Markdown 正文，
>   与业界通用的 agent skills 规范一致。

## 2. 用户故事

作为用户，我把自己沉淀的领域打法写成 `skills/<名称>/SKILL.md`，希望模型在会话里能
自己列出可用技能并按需加载执行，设置里能看到发现了哪些技能、来自哪里。

## 3. 功能需求（FR）

- **FR-1** 技能发现：扫描两处目录下的 `*/SKILL.md`——全局 `<数据目录>/skills/` 与工作区
  `<工作区>/.harness/skills/`；同名时工作区覆盖全局。
- **FR-2** 技能解析：frontmatter 的 `name`/`description` + 正文；`name` 缺省用目录名；
  解析失败的条目跳过且不崩溃。
- **FR-3** 模型侧 `skill` 工具：action=list（全部技能的名称/描述/来源）、action=run +
  `name`（返回该技能完整正文，模型照做）；未知技能报错。
- **FR-4** 按预设与插件开关授权：预设 Tools 含 `skill` 且插件未停用时才挂载（内置 =
  标准、创造；自定义可加）；停用「技能」插件后从下一轮消息消失。
- **FR-5** 设置新增「技能」分区：列出技能（名称、描述、来源徽标 全局/工作区）与路径，
  空态给放置指引；入口在设置左侧导航（DSH 有独立技能 UI 的对齐位）。
- **FR-6** 技能是注册表插件：注册表新增「技能」插件（分类 系统，Tools=["skill"]），
  与其他插件一样可开关、可被 `plugins` 工具管理。
- **FR-7** 内置预设行为变化仅限：标准/创造的工具集多一个 `skill` 工具；其余不变。

## 4. 非功能需求（NFR）

- **NFR-1** 技能文件读取有上限（单文件 64KB 截断），防止巨型文件撑爆上下文。
- **NFR-2** 目录不存在/不可读一律静默降级为空列表。
- **NFR-3** 纯 Go 实现，frontmatter 解析不引入 YAML 依赖（按行读 `key: value`）。

## 5. 验收标准

- AC-1（FR-1/2）：单测——临时目录造全局与工作区技能，发现数量/覆盖关系/缺 name 回退正确。
- AC-2（FR-3）：单测——list 返回全部；run 返回正文；未知技能报错。
- AC-3（FR-4）：单测——标准/创造挂载；停用「技能」插件后 toolSpecs 不含 skill；PTC/极简不挂载。
- AC-4（FR-5）：ui.Tester——设置·技能分区渲染技能行与来源徽标；空态可见指引。
- AC-5（FR-6）：注册表 13 项，一致性测试继续通过。
- AC-6（FR-7）：`go test ./...` 全绿无回归。

  后如有出入，在本 REQ 上修订。

## 7. 决策记录

- 技能走 agent 层回调（同 task/plugins），不进 tools 包：需要 app 的目录知识与数据目录。
- 注册表收录「技能」插件而非 skills 全量进插件页列表：技能数量动态、内容大，插件页
  保持「可开关的内置插件」语义，技能在设置·技能分区展示（FR-5）。
