# REQ-009：后台任务（tool-jobs：job_output / job_list / job_kill）

- 状态：已验证（TEST-009 全部通过）
- 关联：DESIGN-009 · TEST-009 · FEATURE-MATRIX 行 `工具/dsh-tool-jobs`
- 日期：2026-10-30
- 证据：活体核对 `docs/evidence/LIVE-UI-2026-10-30.md` §2.2——standard 预设插件清单：
  **tool-jobs**（Enabled）："Model-facing background job control tools
  (**job_output, job_list, job_kill**) over the ctx.jobs registry"；
  tool-bash 描述含 "optional generic **background-job** support"。

## 1. 背景

长时间命令（启动 dev server、大构建、批处理）会占满一发式 bash 的超时窗口。
DSH 的方案：bash 支持后台运行（进 ctx.jobs 注册表），模型用 job_output / job_list /
job_kill 三个工具管理后台任务。mygo 缺失该能力（README 台账 P1）。

## 2. 用户故事

作为用户，我希望模型能把 dev server、长测试放到后台跑，继续干别的活，随时查看
任务输出、列表，用完杀掉——而不是被 600s 超时掐死或被迫开新会话。

## 3. 功能需求（FR）

- **FR-1（启动）**：bash 工具新增 `background: true` 参数：命令立即返回（含 job id），
  进程转入后台任务注册表继续运行；审批门不变（bash 仍是变更类）。
- **FR-2（查看输出）**：`job_output {job_id, offset?}` 返回自 offset 起的累计输出
  （上限 = Shell 输出上限配置，超出提示继续翻页）与任务状态（running/finished/exit code）。
- **FR-3（列表）**：`job_list` 列出全部任务：id、命令、状态、退出码、启动时间、输出字节数。
- **FR-4（终止）**：`job_kill {job_id}` 杀死任务整棵进程组（进程组语义与 REQ-001 一致）。
- **FR-5（门控）**：注册表第 16 项「后台任务」插件（Tools=[job_output, job_list,
  job_kill]，系统分类）；三个工具同进退（经 preset 工具列表 + enabledTool）。
- **FR-6（生命周期）**：任务注册表为应用级（对齐原版 host 级 ctx.jobs）——跨会话存活；
  输出环形保留（上限 1MB，超出丢头部）；任务结束后仍可查输出。

## 4. 非功能需求

- **NFR-1** 纯标准库；输出缓冲并发安全（子进程写 / 工具读）。
- **NFR-2** 任务无超时（后台语义），杀任务用进程组 SIGKILL。

## 5. 验收标准

- AC-1：`background:true` 启动后 <1s 返回含 job id；`sleep 0.3 && echo done` 的输出
  随后可经 job_output 读到，状态变 finished、exit 0。
- AC-2：job_output 分页：4KB 输出 + 上限 1KB → offset 翻页可读全量。
- AC-3：job_kill 杀 `sleep 30` → 状态 finished、非零退出；job_list 反映。
- AC-4：注册表 16 项；标准/创造 preset 挂载三个工具；停用「后台任务」插件后消失。
- AC-5：`go test ./...` 全绿无回归。

## 6. 范围外

- 任务面板 UI（侧栏 Task Board 形态）→ 后续 UI REQ（本轮以模型工具为界面）。
- 任务持久化（应用退出即失，进程随之终止）；定时任务（dsh-schedule 另立 REQ）。
- PTC run_code 桥接暴露 job 工具（PTC 面板保持最小）。

## 7. 决策记录

- 启动入口放 bash 的 `background` 参数而非独立 `job_start` 工具：与原版
  "tool-bash with optional background-job support" 描述一致，模型学习成本最低。
- 注册表为应用级全局（internal/tools 包级）：对齐 host 级 ctx.jobs，且工具闭包
  无需会话接线；输出环形缓冲 1MB 防失控。
