# REQ-012：快捷键体系（应用菜单加速器）

- 状态：已验证（TEST-012 全部通过）
- 关联：DESIGN-012 · TEST-012 · FEATURE-MATRIX 行 `界面/dsh-client-shortcuts`
- 日期：2026-10-30
- 证据：活体核对 `docs/evidence/LIVE-UI-2026-10-30.md`——侧栏 "New session
  **⌥⌘N**"、账号菜单 "Settings **⌥⌘,**"；`.dsh-ref/dsh-package.json` 含
  `dsh-client-shortcuts` / `client-ui-shortcuts`。

## 1. 背景

mygo 全靠鼠标点击导航；DSH 作为桌面应用带系统级快捷键（新会话、设置等）。
macOS 的正路是把快捷键注册为**应用菜单栏加速器**（MyGo `App.SetMenu` + MenuItem
Accelerator），同时补上原生菜单该有的 App/Edit 角色（复制粘贴进输入框必需）。

## 2. 用户故事

作为用户，我希望 ⌥⌘N 一键新会话、⌥⌘, 打开设置、⌘1/2/3 在对话/轨迹/插件间跳转，
编辑框里 ⌘C/⌘V 照常工作——像原版一样的桌面快捷键体验。

## 3. 功能需求（FR）

- **FR-1（应用菜单栏）**：窗口模式挂载应用菜单：App 角色（关于/退出）、文件
  （新会话 ⌥⌘N、关闭窗口 RoleClose）、编辑角色（剪切/复制/粘贴）、显示
  （对话 ⌘1 / 轨迹 ⌘2 / 插件 ⌘3）、设置 ⌥⌘,。
- **FR-2（动作接线）**：菜单动作复用现有函数——新会话 `newSession`、设置
  `openSettings`、导航 `selectedID = "page:<x>"`；在主线程执行（MyGo 保证）。
- **FR-3（加速器对齐）**：新会话与设置的加速器与原版一致（⌥⌘N / ⌥⌘,）；导航
  ⌘1/2/3 为本实现自定（原版未见对应证据，DESIGN 声明）。
- **FR-4（无头安全）**：菜单构建为纯数据（可无头测试）；仅窗口模式挂载到 App。

## 4. 非功能需求

- **NFR-1** 不用 GlobalShortcut（系统级全局热键会劫持其他应用，原版为应用内快捷键）。
- **NFR-2** 菜单是唯一挂载点，不改输入框按键逻辑。

## 5. 验收标准

- AC-1：buildAppMenu 构建出含全部加速器的菜单（⌥⌘N、⌥⌘,、⌘1/2/3、RoleEdit/RoleClose）。
- AC-2：模拟点击「新会话」项 → 会话创建；「设置」项 → 设置页打开（无头走主区回退）；
  导航项 → selectedID 切换。
- AC-3：`go test ./...` 全绿无回归。

## 6. 范围外

- 应用内非菜单快捷键（Esc 关弹层由 Popover 自带；输入框内快捷键）；
  系统级全局热键；Windows/Linux 菜单栏差异调优。

## 7. 决策记录

- 走应用菜单而非逐控件 KeyDown：macOS 惯例、MyGo 原生支持、编辑角色免费获得输入框
  剪贴板支持；测试可以直接调 item.Click。

## 8. 风险与回退

- 菜单挂载失败仅损失快捷键（try-log）；不挂 SetMenu 时 MyGo 有默认菜单兜底。
