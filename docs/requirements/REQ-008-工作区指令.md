# REQ-008：agent-instructions（工作区指令自动加载）

- 状态：已验证（TEST-008 全部通过）
- 关联：DESIGN-008 · TEST-008 · FEATURE-MATRIX 行 `Agent 核心/dsh-agent-instructions`
- 日期：2026-10-30
- 证据：活体核对 `docs/evidence/LIVE-UI-2026-10-30.md` §2.2——standard 预设插件清单：
  **agent-instructions**（Enabled）："Workspace context loader for
  **AGENTS.md/CLAUDE.md** instruction files"。

## 1. 背景

DSH 在每个会话启动时读取工作区根部的 AGENTS.md（或 CLAUDE.md）项目指令并注入系统
提示词，让模型自动遵守项目约定（构建命令、代码风格、禁忌操作）。mygo 目前完全
没有该机制，用户只能把项目约定写进每条消息。

## 2. 用户故事

作为用户，我在项目根目录写一份 AGENTS.md（构建命令、规范、注意事项），希望每个
在该工作区打开的会话自动遵守这些约定，无需重复交代。

## 3. 功能需求（FR）

- **FR-1（发现）**：按 `AGENTS.md` → `CLAUDE.md` 顺序查找工作区根目录，取第一个
  非空文件；都没有则不注入。
- **FR-2（注入）**：指令以独立段落追加到系统提示词末尾：
  `[工作区指令：<文件名>] 请遵循以下来自工作区的项目指令：` + 正文；单文件上限
  32KB（超出截断并注明）。
- **FR-3（门控）**：注册表第 15 项「工作区指令」插件（系统分类，无工具、贡献系统
  提示词），停用后不注入；默认启用。
- **FR-4（生效范围）**：注入发生在会话 agent 构建时（newAgentFor）——子代理继承
  同一系统提示词；切换工作区/会话/重启 agent 后按新工作区重新发现。

## 4. 非功能需求

- **NFR-1** 纯标准库；文件读取失败静默降级为不注入。
- **NFR-2** 不修改人格段，只做末尾追加，与既有 {cwd} 模板共存。

## 5. 验收标准

- AC-1：工作区有 AGENTS.md → 系统提示词含 `[工作区指令：AGENTS.md]` 与正文；
  只有 CLAUDE.md → 回退使用；两者皆无 → 不注入；AGENTS.md 为空文件 → 回退 CLAUDE.md。
- AC-2：>32KB 的指令被截断并注明。
- AC-3：停用「工作区指令」插件后不注入；默认（无配置）注入。
- AC-4：注册表 15 项；清单卡对无工具插件显示贡献说明而非空工具列表。
- AC-5：`go test ./...` 全绿无回归。

## 6. 范围外

- 子目录嵌套 AGENTS.md（按目录就近发现）；.mygo/ 多文件指令目录；远程指令；
  指令热重载（会话内改文件需重启会话/新消息生效——实际每次 newAgentFor 都会重读，
  已算轻量热加载）。
- 全局用户级指令文件（~/.mygo/AGENTS.md）→ 候选后续。

## 7. 决策记录

- AGENTS.md 优先、CLAUDE.md 兜底（业界通用约定；DSH 描述并列两者，优先级未证实，
  按通用约定实现并声明假设）。
- 32KB 上限：与技能正文上限（64KB）区分——指令进入**每条消息**的系统提示，成本更高，
  上限更紧。
